## Durable format và recovery

- JSON `formatVersion: 1`, filename `<SHA256(logical-id)>.json`; các root con `process-journal`, `http-operations`, `resources` dưới private host root của caller. Caller sản phẩm dùng `~/Library/Application Support/2P Crew v2/host/`; tests chỉ dùng canonical `/private/var/folders/.../T/crew-*`. Root `0700`, file `0600`, owner UID hiện tại, không symlink. Store lock riêng `.writer/host.guard` dùng nguyên Task 1 `ProcessLock`.
- Atomic update: create file tạm exclusive/no-follow → canonical JSON → fsync file → rename → fsync parent directory. Đọc chỉ file đã commit, bỏ `.pending-*`, reject file/version/UID/mode/hardlink sai. Không TTL/compaction unresolved. Lock mất/record hỏng thì từ chối ghi/dispatch, không sửa dữ liệu để đoán ownership.
- Launch reservation fsync exact source/projection trước spawn. Spawn marker độc quyền `O_EXCL` trước fork; partial marker cũng ngăn process thứ hai. Hai launcher đồng thời có barrier trước commit marker: chỉ một child thực sự spawned, không chỉ một READY thành công.
- `proofs/<SHA256(launchId)>-{spawn,ready,tree,stopped}.json`. Helper fsync READY trước gửi IPC; parent channel đóng khi chưa release thì child gated thoát không side effect. Release verifier so companion exact pair/fence/attempt rồi fsync authorization trước gate. `lastObservation`/`lastError` durable; PID/birth/PGID/UID mismatch, missing READY/wait hoặc fork đều giữ unknown.
- Native identity dùng `proc_pidinfo(PROC_PIDTBSDINFO)`, start sec/usec thay cho `ps lstart` giây. Dedicated group bằng detached helper. Supervisor initial child chờ pipe tới khi `NOTE_FORK|NOTE_EXIT` được arm trước exec. Stopped proof cần kernel EXIT và wait đúng initial child, receipt không fork, parent wait đúng helper và `sysctl(KERN_PROC_PGRP)` xác nhận group rỗng. Native unavailable/tamper/query error không thành proof.
- HTTP operation record giữ method/route/phase/canonicalBody/bodyHash/key/response. UUID key khác cho từng mutation/phase; result và finalize tách key. Record chuẩn bị fsync trước send; lost reply/restart replay identical. Response commit immutable. Body sensitive keys bị reject, transport không sửa được nested body. Credential vẫn phải do transport/broker giữ ngoài body; sanitizer không thay trách nhiệm caller loại secret tùy ý. Sau replay/ambiguous reply consumer phải query server attempt/command trước release/later side effect; Task 2 không tự authorize claim.
- Resource record giữ UUID/run/kind/name/identity/state/retention/references/lastError; process owner record giữ exact process instance/start identity riêng; layout giữ root/objects/quarantine identity qua restart. Native `mkdirat`, `openat(O_NOFOLLOW)`, `fstatat(AT_SYMLINK_NOFOLLOW)`, tree scan UID/type/device/link count, `renameatx_np(RENAME_EXCL)` quarantine/recheck và `unlinkat` bằng directory FD. Không fallback recursive `rm` theo stale path. Missing attestation/proof, dirty/artifact/ref/abort giữ dữ liệu; lỗi native/mismatch ghi sanitized code cho retry. Crash sau quarantine rename trước state update có thể recovery bằng cùng inode và path objects thiếu. Abort sau quarantine giữ bytes rồi retry cùng inode.
- Native cache riêng `<root>/native/<sourceSHA256>/`: compiler chỉ đọc private source snapshot `0600`; binary `0700`; metadata source/binary SHA256, dev/inode/UID và cache dev/inode. Verify trước mỗi run/spawn, run kiểm lại sau trả response. Không cài clang hay công cụ toàn máy.
