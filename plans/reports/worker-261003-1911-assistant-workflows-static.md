Proposed internal producer seam for PM freeze: `createWorkflowManifest(registry: Pick<WorkflowRegistry,'resolve'>, renderArtifacts?: DefinitionRenderArtifactReader)` exposes brief's `loadDefinition(source,projection)`. The reader is a captured, project-bound host capability, never an HTTP/client-supplied receipt:

```ts
interface DefinitionRenderArtifactReader {
  // Frozen by the trusted host constructor, never returned by readPinned.
  readonly expected: Readonly<{
    projectRoot: string;
    source: SourcePin;
    projection: ProjectionPin;
  }>;
  readPinned(): Promise<null | {
    projectRoot: string;
    generationRoot: string;
    manifestBytes: Uint8Array;
    readOutput(relativePath: string): Promise<Uint8Array>;
    readCurrentResolvedValues(): Promise<unknown>;
  }>;
}
```

The adapter must compare caller source/projection pins to the host-captured `expected` values before reading. The captured `projectRoot` is the expected scope; the returned `projectRoot` is an observed renderer input to compare, not a new authority source. The adapter calls `registry.resolve` itself and re-reads selected source/projection skill bytes plus `_bmad/scripts/render_skill.py` from those exact roots. It accepts only manifest-declared regular-file paths, checks every source SHA against the pinned projection files, hashes actual output bytes, compares independently read current config/customization values against renderer `inputs`, recomputes root/generation identity with the renderer's canonical JSON semantics, and binds the full verified manifest/output digest into definition SHA. `readOutput` must be confined by the trusted reader to the immutable generation root and reject symlink/traversal. A declared hash, path or boolean from the reader is not evidence by itself. No bound reader or unavailable actual renderer execution means deny. Unit fakes cannot certify production.
